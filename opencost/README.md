# OpenCost: what the cluster would cost

[OpenCost](https://github.com/opencost/opencost) (chart 2.5.35, app 1.121.5) allocates cluster cost to namespaces, pods and nodes. It reads usage from kube-prometheus-stack's Prometheus and **exports its own cost metrics back to Prometheus**, which a Grafana dashboard displays.

| Where | What |
| --- | --- |
| Grafana → **OpenCost / Cluster cost (olympians)** | Monthly cluster, allocated, idle and storage cost; cost per namespace; cost per node |
| Grafana → **OpenCost / Cost centers (olympians)** | Chargeback: cost per `cost-center` label (pod/PVC label, else namespace label, else `unallocated`), idle shown separately, and a cost-center × namespace table. See `cost-centers/README.md` |
| https://opencost.faultycloud.xyz | OpenCost's own UI and API (`/model/allocation/compute?window=1d&aggregate=namespace`). LAN only, no login |

| Task | Command (from `opencost/`) |
| --- | --- |
| Install / upgrade | `make helm` (runs `prerequisites`: namespace and dashboard ConfigMap). Needs `monitoring/` first |
| Regenerate the dashboards | edit `hack/gen-dashboard.py`, run `python3 hack/gen-dashboard.py` (writes both ConfigMaps), then `make prerequisites` |
| Remove | `make uninstall-helm` |

## Prices: cloud-equivalent
`helm/values.yaml` → `customPricing.costModel`, set explicitly to OpenCost's own defaults (`configs/default.json`, GCP `us-central1` list prices). The figures answer **"what would these workloads cost in a public cloud"**, not the home bill.

| Resource | Price | ≈ per month (×730 h) |
| --- | --- | --- |
| CPU | $0.031611 per vCPU-hour | $23.08 per vCPU |
| RAM | $0.004237 per GiB-hour | $3.09 per GiB |
| Storage | $0.00005479452 per GiB-hour, one price for every StorageClass | $0.04 per GiB |

**Don't use the chart's example `costModel`** (CPU 1.25, RAM 0.50, storage 0.25). OpenCost's docs say it gives "substantially higher" costs: about 40× CPU and 4,500× storage. To price the real home cost, replace these four numbers with your hardware amortisation plus electricity per vCPU, GiB and GiB of storage, then run `make helm`.

**On 2026-11-25** the dashboard showed:
- **Cluster:** about $4,630/month. Each worker is about $1,497/month (48 vCPU, ~125 GiB); zeus is about $140/month.
- **Allocated compute:** about $544/month, of which `rook-ceph` is about $388.
- **Idle compute:** about $4,086/month.
- **Storage:** about $15/month.

Most of the cluster is idle capacity.

## How it's wired
- **Reading:** from `kube-prometheus-stack-prometheus.monitoring.svc.cluster.local:9090`.
  - **Gotcha:** the chart's `clusterName` is used as the **DNS domain** in that URL. It must stay `cluster.local`. Setting it to `olympians` produced `…svc.olympians`, which doesn't resolve. The cluster's name in cost data is `exporter.defaultClusterId: olympians`.
- **Exporting:** a ServiceMonitor scrapes `opencost:9003/metrics` every 1m with `honorLabels: true`, as OpenCost recommends. The metrics keep their workload `namespace`, `pod` and `node` labels, which the per-namespace panels need. Metrics include `node_{cpu,ram,total}_hourly_cost`, `pv_hourly_cost`, `container_cpu_allocation` and `container_memory_allocation_bytes`.
- **Dashboards:** generated by `hack/gen-dashboard.py` into `base/grafana-dashboard.yaml` and `base/grafana-dashboard-cost-centers.yaml`, ConfigMaps labeled `grafana_dashboard: "1"`. The Grafana sidecar loads those from any namespace. Their queries:
  - **deduplicate with `max by (…)`**, because after an OpenCost restart the old pod's series linger for Prometheus's 5-minute lookback and would double every cost
  - **price storage on each PV's size**, mapped to the claim's namespace through `kube_persistentvolume_claim_ref`
- **Pod Security `restricted`:**
  - The exporter runs as UID 1000 with a read-only root filesystem.
  - **The UI must run as 1001:1000**, the owner of `/var/www` and `/etc/nginx` in its image. Its entrypoint rewrites files there with `sed` and crashes with "Permission denied" as UID 1000.

**Cost centers on 2026-11-26:** `platform` about $559.69/month, `brietzke` about $2.24/month, `unallocated` $0. Idle capacity, about $4,083/month, is shown separately. The cost-center totals ($561.93, including $15.04 of storage) plus idle add up to cluster cost ($4,630, compute only) plus storage.
